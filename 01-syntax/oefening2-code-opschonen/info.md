# Oefening 01.2 — Code opschonen

- **Thema:** Syntax
- **Moeilijkheidsgraad:** Makkelijk
- **Bestanden:** `index.html` (start), `oplossing.html` (voorbeeld), `styles.css` (styling)

## Opdracht

In `index.html` staat een pagina die vol fouten zit. Herschrijf de HTML zodat die voldoet
aan de huisregels van deze cursus.

## Vereisten

- [ ] Kleine letters voor alle tags en attributen
- [ ] Dubbele quotes rond alle attribuutwaarden
- [ ] Consequente inspringing (tabs óf spaties, geen mix)
- [ ] Correcte nesting van elementen
- [ ] Volledige basisstructuur met `lang="nl"` en een correcte `<head>`

## Tips

- Selecteer in VS Code alles en druk op Shift+Alt+F om de inspringing automatisch te herstellen.

## Afbeeldingen

- Geen lokale afbeeldingen nodig.
